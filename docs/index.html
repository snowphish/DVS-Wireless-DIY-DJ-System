Wireless DIY DVS Flasher

Install the current receiver or puck firmware directly over USB. No Arduino IDE is required.

Web Serial is unavailable. Use desktop Chrome or Edge and open this page over HTTPS.

Flashing steps

  1. Connect the board directly with a USB data cable. Turn a battery-powered puck off first.
  2. Select the exact board and gyro variant above.
  3. Click Connect and flash, choose its serial port, and approve the installation.
  4. If the board is not detected, hold its BOOT button while tapping RESET, then try again.
  5. Flash the receiver first, then both pucks. Power the receiver before switching the pucks on for pairing.

Traktor limitation: Traktor mode is a carrier-only signal for speed and direction in Relative mode. It is not currently detected as genuine MK2 timecode. Disable Traktor's timecode error messages/warnings before use. Serato mode outputs full CV02 timecode.
